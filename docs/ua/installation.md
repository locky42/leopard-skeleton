# Встановлення

## 1. Через Docker (з файлом Makefile) — Рекомендовано

1. **Запустіть повне автоматичне встановлення:**
    ```bash
    make install
    ```
    *Ця команда інтерактивно запустить `./install.sh` для вибору конфігурації бази даних, встановіть Composer-пакунки на вашій хост-машині, згенерує локальні SSL-сертифікати та підніме Docker-контейнери.*

2. **Відредагуйте файли конфігурацій (За потреби):**
    Якщо вам потрібно змінити дефолтні налаштування, відредагуйте наступні файли:
    * `.env`
    * `./config/app.php`
    * `./config/routes.yaml`
    * `./public/.htaccess`

3. **Відкрийте проєкт:**
    Перейдіть у браузері за адресою: [http://localhost:8080](http://localhost:8080)

---

## 2. Через Docker (Вручну)

1. **Згенеруйте конфігураційні файли та налаштуйте права:**
    ```bash
    ./install.sh
    ```
    *Оберіть потрібний драйвер бази даних та налаштуйте змінні оточення через інтерактивне CLI-меню.*

2. **Відредагуйте файли конфігурацій (За потреби):**
    Перевірте та оновіть створені файли конфігурації, якщо це необхідно:
    * `.env`
    * `./config/app.php`
    * `./config/routes.yaml`
    * `./public/.htaccess`

3. **Запустіть Docker-контейнери:**
    ```bash
    docker compose up -d --build
    ```

4. **Встановіть залежності всередині контейнера:**
    ```bash
    docker compose exec web composer install
    ```

5. **Відкрийте проєкт:**
    Відкрийте проєкт у браузері за портом, який вказано у вашому файлі `.env` (дефолтний: [http://localhost:8080](http://localhost:8080)).

---

## 3. Розгортання на LAMP

1. **Згенеруйте конфігураційні файли:**
    ```bash
    ./install.sh
    ```

2. **Встановіть composer пакунки локально:**
    ```bash
    composer install
    ```
    *Якщо виникають конфлікти платформи через версію PHP на хост-машині, використовуйте команду `composer install --ignore-platform-reqs`.*

3. **Відредагуйте файли конфігурацій:**
    Змініть згенеровані файли конфігурації відповідно до налаштувань вашого локального оточення Apache:
    * `.env`
    * `./config/app.php`
    * `./config/routes.yaml`
    * `./public/.htaccess`

4. **Відкрийте проєкт:**
    Відкрийте проєкт у браузері за URL-посиланням, що визначене налаштуваннями вашого локального віртуального хосту в Apache.
